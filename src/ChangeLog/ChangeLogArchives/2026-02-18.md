# 18 Février 2026 - V0.3.0

---

### Résumé

- Nouvelle fonctionnalité : Sélecteur d'icônes personnalisés pour les sorts
  1. Les utilisateurs peuvent maintenant ajouter des icônes uniques à côté du nom de chaque sort
  2. Choix parmi une liste d'icônes par défaut ou possibilité d'ajouter des emojis personnalisés
  3. Les icônes sont stockées localement dans le navigateur et persistantes
  4. Les emojis personnalisés utilisés sont automatiquement ajoutés à la liste disponible pour les prochaines utilisations

### Détails

**Nouvelles Fonctionnalités:**
- Clic sur le cercle (◯) à côté du nom d'un sort ouvre un sélecteur d'icônes
- Icônes disponibles par défaut : ⭐, 🔥, ❄️, ⚡, 💀
- Champ d'entrée pour ajouter des emojis personnalisés
- Bouton pour supprimer l'icône d'un sort
- Stockage local automatique des préférences d'icônes et des emojis personnalisés

**Améliorations UI:**
- Modal de sélection d'icônes avec interface intuitive
- Grille d'icônes en 5 colonnes
- Support du clavier (touche Entrée pour valider un emoji personnalisé)
- Indicateurs visuels pour les emojis actuellement sélectionnés
