# 18 Février 2026 - V0.3.0

---

### Résumé

- Nouvelle fonctionnalité : Sélecteur d'icônes personnalisés pour les sorts avec support des emojis custom
- Création d'un script automatisé pour générer/mettre à jour les changelogs
- Popup de notification pour les nouveaux changelogs
- Corrections de bugs dans les descriptions de sorts

### Détails

**Nouvelles Fonctionnalités:**

*Sélecteur d'Icônes pour les Sorts:*
- Clic sur le cercle (◯) à côté du nom d'un sort ouvre un sélecteur d'icônes modal
- Icônes disponibles par défaut : ⭐, 🔥, ❄️, ⚡, 💀
- Possibilité d'ajouter des emojis personnalisés via un champ d'entrée
- Les emojis personnalisés sont automatiquement sauvegardés et disponibles pour les futures utilisations
- Bouton "Supprimer l'icône" pour désaffecter un icon d'un sort
- Support du clavier : appuyer sur Entrée pour valider un emoji personnalisé

*Stockage Persistant:*
- Les icônes de sorts sont stockées sous la clé `spellIcons`
- Les emojis personnalisés utilisés sont stockés sous la clé `customEmojis`
- Toutes les données persistent au rechargement de la page

*Script Changelog:*
- Commande `npm run changelog` pour créer/mettre à jour les changelogs interactivement
- Détecte automatiquement si un changelog existe pour aujourd'hui
- Propose de mettre à jour le changelog existant ou d'en créer un nouveau
- Support du clavier (Entrée pour valider)

*Popup Notification:*
- Affichage automatique d'un popup lors du chargement de la page si un nouveau changelog est disponible
- Design moderne avec gradient et animation fluide
- L'utilisateur peut fermer le popup facilement
- Stocke la dernière version vue pour éviter les notifications répétées

**Améliorations UI:**
- Modal de sélection d'icônes avec interface intuitive
- Grille d'icônes en 5 colonnes avec espacement optimisé
- Effet de survol avec changement de couleur de bordure
- Indicateurs visuels pour les emojis actuellement sélectionnés (fond bleu clair #e0f2fe)
- Remplacement de l'emoji ⭐ par 🆕 pour les nouveaux sorts (meilleure visibilité)
- Modal scrollable pour le popup de notification (support des longs contenus)

**Corrections:**
- Correction du texte du sort "Sleet Storm" : "concentration de José" remplacé par "perdre la concentration"

**Architecture:**
- Intégration du composant `ChangelogPopup` dans le composant App principal
- Utilisation des hooks React pour la gestion d'état
- Stockage local via le système de persistence existant (`PersistData.js`)
- Rendering dynamique de la grille d'icônes basée sur les options disponibles
